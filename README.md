# Kiwoom Automated Trading System / 키움 자동매매 시스템

## 🇺🇸 Introduction
This is an advanced automated trading system connecting **Kiwoom Securities (Open API)** with **Macroeconomic Data**.
It uses a **Hybrid Architecture**:
- **Kiwoom Bridge (32-bit)**: Handles HTS interactions.
- **Main Bot (64-bit)**: Handles Logic, Macro Data, and Strategy.

👉 **Please read [walkthrough.md](walkthrough.md) for detailed setup instructions.**

---

## 🇰🇷 소개
이 프로젝트는 **키움증권 Open API**와 **거시경제 데이터(매크로)**를 결합한 고급 자동매매 시스템입니다.
**하이브리드 아키텍처**를 사용합니다:
- **키움 브리지 (32비트)**: HTS와의 통신 담당.
- **메인 봇 (64비트)**: 매매 로직, 거시 데이터 분석, 전략 실행 담당.
